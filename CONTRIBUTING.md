# Contributing

Thank you for improving this Azure-mapped grid reliability intelligence platform.

## Development Setup

1. Create and activate a Python 3.11+ virtual environment.
2. Run `make install`.
3. Run `make quality` before opening a pull request.

## Scope Discipline

Milestone 1 is limited to repository foundation, architecture documentation, configuration, and shared utilities. Later milestones should add data generation, ingestion, forecasting, reliability analytics, and operations capabilities in small, reviewable increments.

## Quality Expectations

Contributions should be typed, deterministic, locally runnable, and honest about whether functionality is local, simulated, planned, or Azure-deployed. Do not commit secrets, generated datasets, trained models, local caches, or runtime outputs.
