# Security Policy

## Supported Versions

The repository is in an early scaffold phase. Security fixes should target the default branch.

## Reporting a Vulnerability

Do not open public issues containing secrets, credentials, exploitable details, or sensitive operational data. Report security concerns privately to the repository maintainer.

## Handling Secrets

This project must not contain Azure keys, connection strings, service principals, tokens, customer data, or live grid operational data. Use `.env.example` for non-secret configuration examples only.
