# Azure Monitor Mapping

Milestone 8 remains local-only.

- Structured monitoring CSV/JSON records map conceptually to Azure Monitor and
  Log Analytics tables.
- Component run traces map conceptually to Application Insights telemetry.
- Forecast and outage-prediction checks map conceptually to Azure Machine
  Learning monitoring.
- Contract and lineage records map conceptually to Microsoft Purview.
- CSV and JSON outputs are Power BI-ready, but no Power BI project file or
  dashboard is created.

No Azure monitoring resources, credentials, workspaces, dashboards, or alert
actions are deployed.
