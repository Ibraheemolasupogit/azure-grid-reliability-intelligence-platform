# Maintenance Prioritisation

Maintenance priority is a review queue, not a work schedule or optimisation result.

| Priority | Meaning |
| --- | --- |
| `P1_IMMEDIATE_REVIEW` | critical condition on a high-criticality asset |
| `P2_HIGH` | critical or degraded evidence requiring high-priority review |
| `P3_MEDIUM` | watch-list evidence, non-routine reasons, or moderate criticality |
| `P4_ROUTINE` | routine monitoring |
| `DATA_REVIEW_REQUIRED` | evidence completeness below the configured minimum |

Priority rules combine condition band, criticality tier, inspection status, deferred maintenance, recent direct unplanned outage involvement, and operational status.

The priority output keeps supporting reason codes so reviewers can see why an asset was elevated.
