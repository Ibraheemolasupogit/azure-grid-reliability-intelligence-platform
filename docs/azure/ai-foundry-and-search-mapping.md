# AI Foundry And Search Mapping

The local assistant source registry, extraction, chunking, lexical retrieval,
grounding, citations, safety, prompt audit, and evaluation map conceptually to
Azure AI Foundry, Azure AI Search, Storage, managed identity, Key Vault, and
Azure Monitor.

Provider, model, quota, and index settings remain placeholders. Citation
metadata, source checksums, lineage, refusal controls, no-chain-of-thought
storage, and no autonomous operational action remain mandatory controls.

No Azure OpenAI deployment or model call is configured.
