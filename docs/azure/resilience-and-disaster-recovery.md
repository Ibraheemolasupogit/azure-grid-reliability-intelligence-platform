# Resilience And Disaster Recovery

Status: `BLUEPRINT_ONLY`.

Proposed targets must be approved before deployment. Storage redundancy,
zone-aware services, paired-region recovery, Key Vault soft delete and purge
protection, Event Hubs recovery, Azure Data Explorer backup/export patterns, AML
artifact recovery, AI Search index rebuild, monitoring continuity, Power BI
workspace recovery, and Git-based IaC recovery are documented design concerns.

Example classes: development best effort, test recoverable, production formal
RPO/RTO. These are not contractual commitments.
