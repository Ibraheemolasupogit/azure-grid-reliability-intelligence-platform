# Power BI Page Design

Dashboard specifications are written under `dashboard/page-specifications/` and
wireframes under `dashboard/wireframes/`.

The specified pages are:

1. Executive overview.
2. Grid operations.
3. Demand forecasting.
4. Asset health.
5. Outage risk.
6. Reliability.
7. Data and model monitoring.
8. Grid operations assistant.
9. Governance and lineage.

These are design assets only. No report has been implemented or deployed in
Power BI Desktop, Power BI Service, or Microsoft Fabric.
