# DAX Measures

Text DAX definitions are written to `dashboard/dax/measures.dax` and described
in `dashboard/dax/measure-catalogue.md`.

The definitions reference the local semantic model table names. Measures use
safe division for ratios and document that SAIFI, SAIDI, CAIDI, WAPE, and
assistant grounding rates are non-additive. The DAX file is not deployed.
