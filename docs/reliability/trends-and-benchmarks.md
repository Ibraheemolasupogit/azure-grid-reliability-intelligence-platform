# Trends and Benchmarks

Trend outputs compare the current period with the previous period for each entity and metric.

Trend fields include:

- current value;
- previous value;
- absolute change;
- percentage change;
- direction.

When a prior period does not exist or the prior value is zero, percentage change is `null`.

Benchmarks are internal synthetic peer comparisons only. The default method is peer median by entity type. No real operator, Ofgem, National Grid, or external benchmark data is used.
