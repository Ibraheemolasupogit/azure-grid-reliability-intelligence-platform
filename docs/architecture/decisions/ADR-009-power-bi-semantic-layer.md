# ADR-009: Power BI Semantic Layer

Status: BLUEPRINT_COMPLETE

Context: Milestone 10 emits dimensions, facts, bridges, DAX, and specs.

Decision: Map those outputs to Power BI semantic model or Fabric serving patterns.

Alternatives: Build a custom dashboard application.

Consequences: Reporting remains aligned with Microsoft analytics tooling.

Security implications: RLS and workspace separation required before deployment.

Cost implications: Power BI/Fabric capacity must be planned.
