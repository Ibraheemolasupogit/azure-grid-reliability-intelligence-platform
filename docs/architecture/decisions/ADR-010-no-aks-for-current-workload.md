# ADR-010: No AKS For Current Workload

Status: BLUEPRINT_COMPLETE

Context: The platform is batch, reporting, monitoring, and governed assistant oriented.

Decision: Do not include AKS in Milestone 11.

Alternatives: Add Kubernetes for portfolio breadth.

Consequences: Lower operational complexity and fewer network/security surfaces.

Security implications: Avoids cluster hardening scope.

Cost implications: Avoids cluster baseline cost.
