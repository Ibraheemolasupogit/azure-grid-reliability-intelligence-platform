# Grounding And Citations

Grounding statuses are `GROUNDED`, `PARTIALLY_GROUNDED`,
`INSUFFICIENT_EVIDENCE`, `CONFLICTING_EVIDENCE`, and `RESTRICTED_REQUEST`.

Every substantive response is tied to retrieved evidence and stable local
citations such as `[SRC-001]`. Citation records retain source ID, relative path,
section, source run ID where available, content hash, and claim type.
